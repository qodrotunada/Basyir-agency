# Credits and content status

- All interface code, CSS illustrations, and interface text in this prototype are authored for the Basyir Agency project.
- Scene artwork is built with inline SVG and CSS. No external scene image assets are bundled.
- Arabic example sentences and episode concepts are based on `Basyir_Agency_Spesifikasi_Terpadu_Final_vNext.1`, uploaded for this implementation.
- The project does not include verified human Arabic audio recordings. The player uses the browser's Arabic speech synthesis as an optional fallback when the browser/device provides it. This is not a substitute for teacher-reviewed recordings.
- Arabic diacritics, transliteration, translations, puzzle accepted orders, and checkpoint items remain draft content pending approval by an Arabic teacher or qualified speaker, as required by the specification.
- Optional typography loads DM Sans, DM Mono, and Manrope from Google Fonts. System sans-serif fallbacks are defined for environments without network access.
